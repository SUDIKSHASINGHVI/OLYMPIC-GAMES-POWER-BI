# 🏅 Olympic Games Power BI Dashboard

An interactive **Power BI data analytics project** built using historical Olympic Games data.  
The project combines athlete, event, country, games, results, and medal information to explore Olympic performance and uncover meaningful insights through data visualization.

## 📌 Project Overview 

The **Olympic Games Power BI Dashboard** provides an analytical view of Olympic history using multiple related datasets. It is designed to answer questions such as:

- Which countries have performed best across Olympic Games?
- How have medal counts changed over time?
- Which athletes and sports have achieved outstanding results?
- How are Olympic events distributed across years and countries?
- What patterns can be identified in Gold, Silver, and Bronze medal performance?

The project demonstrates practical skills in **data cleaning, data modeling, DAX, interactive visualization, and business-style storytelling with data**.

## 🎯 Objectives

- Analyze historical Olympic performance.
- Build relationships between multiple datasets.
- Create meaningful KPIs and calculated measures.
- Identify medal and participation trends.
- Compare countries, athletes, sports, and Olympic editions.
- Present insights through an interactive Power BI dashboard.

## 🗂️ Dataset Structure

The project uses the following datasets:

| Dataset | Description |
|---|---|
| `Olympic_Athlete_Bio.csv` | Athlete-level information |
| `Olympic_Athlete_Event_Results.csv` | Athlete participation and event results |
| `Olympic_Games_Medal_Tally.csv` | Medal counts by country and Olympic Games |
| `Olympic_Results.csv` | Olympic event/result information |
| `Olympics_Country.csv` | Country-related information |
| `Olympics_Games.csv` | Olympic Games editions and related details |

The large CSV files are stored using **Git LFS**.

## 🚀 How to Use

1. Clone or download this repository.
2. Open the Power BI `.pbix` file in **Microsoft Power BI Desktop**.
3. Ensure the dataset paths are correctly configured.
4. Refresh the data if required.
5. Use the dashboard filters and slicers to explore the Olympic data.

> **Note:** Power BI Desktop is required to open and edit the `.pbix` dashboard.
